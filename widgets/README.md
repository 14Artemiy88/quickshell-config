# quickshell-widgets

Quickshell widgets and system modules for a compact, highly configurable desktop setup.

## Русский

`quickshell-widgets` — набор настраиваемых виджетов и модулей для Quickshell.

Основные возможности:
- Player с поддержкой нескольких backend'ов, приоритетом проигрывателей и seek;
- отдельный Mopidy-модуль с Queue, браузером файлов, поиском, плейлистами, Volume/Mute, Shuffle/Repeat и управлением содержимым плейлистов;
- Calendar, Clock, Weather, Volume, Network, System Monitor, CPU/RAM и Cava;
- независимые настройки внешнего вида, цветов, шрифтов, размеров и положения модулей;
- профили настроек, сохранение/загрузка и сброс параметров;
- режим редактирования положения модулей и отдельное перемещение окна настроек.

### Установка

Проект предназначен для Quickshell. Запустите `install.sh` или подключите конфигурацию к своему Quickshell setup вручную.

### Настройки

Основные настройки находятся в окне Settings. Для модулей доступны отдельные параметры геометрии, внешнего вида и поведения. Mopidy включается независимо от обычного Player.

## English

`quickshell-widgets` is a collection of configurable Quickshell widgets and system modules.

Highlights:
- multi-backend Player with configurable backend priority and seek support;
- a separate Mopidy module with Queue, file browser, search, playlists, Volume/Mute, Shuffle/Repeat, and playlist editing;
- Calendar, Clock, Weather, Volume, Network, System Monitor, CPU/RAM, and Cava;
- per-module typography, colors, sizes, geometry, and behavior settings;
- settings profiles with save/load and reset support;
- module layout editing and independent settings-window moving.

### Installation

The project is intended for Quickshell. Run `install.sh` or integrate the configuration into your existing Quickshell setup manually.

### Settings

Most configuration is available from the Settings window. Modules expose their own geometry, appearance, and behavior controls. Mopidy can be enabled independently from the main Player.
