# desktop-shell

Standalone Quickshell desktop shell.

## Features
- Modular desktop widgets with persistent geometry, appearance and behavior settings.
- **Умное редактирование**: скрывает окно настроек и позволяет перетаскивать видимые блоки прямо на рабочем столе; **Esc** возвращает настройки.
- Profiles with instant save/load/delete and themed selectors.
- Built-in themes: **14 Theme**, Catppuccin Mocha, Tokyo Night, Dracula, Nord, Gruvbox Dark, One Dark, Amber, Purple, Ice, Mono.
- Theme editor with save-as-custom support.
- Weather resilience, adaptive timer/volume widgets, configurable player/CAVA/weather presentation.
